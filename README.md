# iPAS AI 應用規劃師題庫（初級＋中級）

用經濟部 iPAS「AI 應用規劃師」**官方公告試題**練習的網站。手機、電腦都能用，不用註冊。

**👉 開始練習：<https://stevet7321.github.io/ipas-ai-planner/>**

- 初級：<https://stevet7321.github.io/ipas-ai-planner/?level=1>
- 中級：<https://stevet7321.github.io/ipas-ai-planner/?level=2>

## 收錄內容

| 等級 | 科目 | 收錄卷別 | 題數 |
|---|---|---|---|
| 初級 | L11 人工智慧基礎概論、L12 生成式 AI 應用與規劃 | 114 年第四梯次，115 年第一、二、三次 | 400 |
| 中級 | L21 人工智慧技術應用與規劃（必考）、L23 機器學習技術與應用 | 114 年第二梯次，115 年第一次 | 200 |

- 題目和答案都照官方公告，不修改。
- 每題依《評鑑內容範圍參考》（115.06 版）歸到官方章節。
- 每題都有逐選項解析，四個選項分別說明為什麼對、為什麼錯。
- 考同一個概念的題目共用一份主題講義，共 154 份。初級講義的寫法以沒有技術背景的讀者為對象。
- 有些題目兩個選項都說得通，或題幹有事實錯誤、答案已經過時。這些題目答案照官方，但會另外顯示「整理者註記」說明。

## 功能

- **章節練習**：選一章（或整科）逐題作答，答完馬上看解析和講義。可以只做沒做過的題目，或只做答錯過的題目。
- **模擬考**：照官方題數與時間限時作答（初級每科 50 題 75 分鐘，中級每科 50 題 90 分鐘），交卷後逐題檢討。可以考原卷，也可以從所有卷依章節比例隨機抽題。
- **錯題本**：答錯的題目會自動收進來，同一題累積答對 2 次就移出。
- **官方資源**：原卷 PDF、學習指引、簡章的官方連結。

作答進度只存在你目前用的瀏覽器裡，不會上傳。換裝置時，可以在「官方資源」頁匯出進度檔，再到新裝置匯入。

## 來源與聲明

- 題目來源是 [iPAS AI 應用規劃師學習資源頁](https://ipd.nat.gov.tw/ipas/certification/AIAP/learning-resources) 公告的試題，著作權屬原出題單位。
- 考試日期、規則、範圍以 iPAS 官方簡章和《評鑑內容範圍參考》為準。
- 章節分類、逐選項解析、主題講義、整理者註記都是整理者補充的，**不是官方內容**，僅供學習參考。這些內容由 AI 協助撰寫，再經過另一輪獨立審查和事實查證，但仍可能有錯。發現錯誤歡迎開 Issue。
